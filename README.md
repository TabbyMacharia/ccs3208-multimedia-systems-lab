# CCS 3208 Multimedia Systems Laboratory

This repository contains my laboratory work for CCS 3208: Multimedia Systems.

## Week 2 Laboratory

The practical focuses on digital audio signal processing, image processing, video frame processing, and basic digital audio synthesis using Python.

### Parts Covered

- Part A: Digital Audio Generation and Analysis
- Part B: Audio Gain, Mixing, Delay and Echo
- Part C: Image Point Processing
- Part D: Image Neighbourhood Processing
- Part E: Video Frame Processing
- Part F: Digital Audio Synthesis and Integration

## Tools and Libraries

- Python
- NumPy
- Matplotlib
- Pillow
- OpenCV

## Key Topics

The practical covers:

- Digital audio sampling and waveform generation
- Amplitude scaling and clipping
- Audio mixing and delay/echo
- Image brightness adjustment
- Image negatives and thresholding
- Image smoothing and sharpening
- Video frame extraction and processing
- Video frame resizing
- Sine-wave synthesis
- Harmonics and additive synthesis
- ADSR envelopes
